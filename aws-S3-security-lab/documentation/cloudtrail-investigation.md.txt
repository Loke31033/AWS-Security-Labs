## Investigation

### Who?

The CloudTrail `userIdentity` field identifies the principal that performed the API operation.

### What?

The `eventName` was `DeleteBucketPolicy`.

This operation removes a bucket policy from an S3 bucket.

### When?

The operation occurred at the timestamp recorded in the `eventTime` field.

### Where?

The event contains the source IP address and AWS Region associated with the request.

### Result

The event was reviewed for `errorCode` and `errorMessage` to determine whether the operation succeeded or failed.

## Security Relevance

Bucket-policy changes are security-sensitive because bucket policies can control access to S3 resources.

CloudTrail provides an audit trail that allows security analysts to investigate these API operations.
