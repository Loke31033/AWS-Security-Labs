# S3 Security Remediation

## 1. Objective

Remediate the intentionally introduced S3 public-access
misconfiguration and restore the bucket to a secure baseline.

---

## 2. Identified Issue

The lab temporarily introduced an insecure S3 configuration
to simulate a cloud security incident.

The simulated configuration included:

- Public access configuration
- A bucket policy using `Principal: "*"`
- `s3:GetObject` permission

No sensitive or production data was used.

---

## 3. Remediation Actions

### Step 1 — Remove Public Bucket Policy

The intentionally created public bucket policy was removed.

This prevents the test policy from continuing to grant
public object access.

### Step 2 — Enable S3 Block Public Access

All four S3 Block Public Access controls were enabled:

- Block public ACLs
- Ignore public ACLs
- Block public bucket policies
- Restrict public bucket access

### Step 3 — Verify Encryption

S3 server-side encryption was verified to remain enabled.

### Step 4 — Verify Versioning

S3 versioning was verified to remain enabled.

### Step 5 — Validate with IAM Access Analyzer

IAM Access Analyzer was checked after remediation to verify
the resulting access configuration.

### Step 6 — Verify Monitoring

CloudTrail and EventBridge monitoring remained enabled so that
future security-sensitive API activity can be investigated.

---

## 8. Lessons Learned

### Preventive controls

Security controls such as S3 Block Public Access should be
enabled by default wherever appropriate.

### Detective controls

Preventive controls alone are not sufficient. CloudTrail,
EventBridge, CloudWatch Logs, and IAM Access Analyzer provide
visibility into security-relevant activity.

### Investigation

CloudTrail provides valuable information such as:

- Who performed an action
- What API operation occurred
- When it occurred
- Source IP
- AWS Region
- Affected resource
- Success or failure

### Response

A cloud security analyst should:

```text
Detect
  ↓
Investigate
  ↓
Identify root cause
  ↓
Remediate
  ↓
Validate
  ↓
Document
